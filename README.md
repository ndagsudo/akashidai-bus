# 明石台バス検索

明石台七丁目・明石台公園前 と 泉中央駅 の間のバス時刻を検索する、個人専用のバス時刻検索アプリです。
特に「泉中央駅から帰宅する際、明石台七丁目行きを待っていて明石台公園前行きを見逃さないようにする」ことを目的としています。

iPhoneのSafariから「ホーム画面に追加」してPWA（Progressive Web App）として使えます。

**公開URL: https://ndagsudo.github.io/akashidai-bus/**

---

## ファイル構成

```
akashidai-bus/
├── index.html          メインページ
├── style.css           スタイルシート
├── app.js               検索ロジック・画面描画

├── service-worker.js    オフラインキャッシュ
├── data/
│   └── timetable.json   時刻表データ（ダイヤ改正時はここだけ更新）

│   ├── icon-192.png     ホーム画面アイコン（要生成）
│   └── icon-512.png     スプラッシュ用アイコン（要生成）
└── README.md            このファイル
```

## セットアップ手順

### 1. アイコンを生成する（初回のみ）

`icons/generate-icons.html` をブラウザ（Chrome推奨）で開いてください。

1. 「icon-192.png をダウンロード」ボタンをクリック
2. 「icon-512.png をダウンロード」ボタンをクリック
3. ダウンロードした2ファイルを `icons/` フォルダに移動

### 2. ローカルで確認する

ローカルサーバーが必要です（`file://` では Service Worker が動作しません）。

**Python の場合：**
```bash
cd akashidai-bus
python -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

**Node.js の場合：**
```bash
npx serve akashidai-bus
```

1. GitHubで新しいリポジトリを作成（例：`akashidai-bus`）
2. このフォルダをそのリポジトリにプッシュ

```bash
cd akashidai-bus
```

## iPhoneのホーム画面に追加する方法

1. SafariでアプリのURLを開く
2. 画面下の「共有」ボタン（□↑）をタップ
3. 「ホーム画面に追加」をタップ
4. 名前を確認して「追加」をタップ

ホーム画面からアプリアイコンをタップすると、アドレスバーなしのアプリ風表示になります。

## 使い方

### ホーム画面

- **「行き」**（明石台 → 泉中央駅）、**「帰り」**（泉中央駅 → 明石台）の2つの大きなボタンから選びます。

### 検索結果画面

- 現在時刻に基づいて次に乗れる便が自動的に表示されます。
- 「帰り」では、明石台七丁目行きと明石台公園前行きが発車時刻順に1つの一覧にまとまり、**明石台公園前行きが先に出る場合は警告バナー**で知らせます。
- 各便には発車までの「あと◯分」が表示され、1分ごとに自動更新されます。5分を切った便は赤く強調表示されます。

### ボタンの機能

| ボタン | 動作 |
|---|---|
| 時刻を更新 | 現在時刻で再検索します |
| 全便を見る | 当日の全便を一覧表示します（既に発車した便はグレー表示） |
| 現在時刻に戻る | 日時指定を解除し、現在時刻での検索に戻ります |
| 日時を指定 | 任意の日付・時刻を指定して検索します（「明日の19時に出たら」等のシミュレーションに便利） |

## 時刻表データの更新方法（ダイヤ改正があったとき）

`data/timetable.json` だけを編集すれば反映されます。アプリ本体（HTML/CSS/JS）を触る必要はありません。

### 構造

```json
{
  "meta": {
    "confirmedDate": "2026-11-23",   // データを確認した日付。90日を超えると「更新確認が必要」の警告が出ます
    "specialScheduleDates": [
      { "date": "2026-12-31", "dayType": "holiday" }  // 年末年始などの特別ダイヤを手動指定する場合
    ]
  },
  "directions": {
    "outbound": { ... },  // 明石台 → 泉中央駅
    "inbound":  { ... }   // 泉中央駅 → 明石台
  }
}
```

各路線の `schedules` に `weekday`（平日） / `saturday`（土曜） / `holiday`（日祝）の3種類の時刻配列があります。
`time` は `"HH:MM"` 形式、`note` は「学＝東北学院大学経由」のような注記（任意）です。

### データの出典

- 明石台七丁目: https://transfer.navitime.biz/miyagikotsu/pc/diagram/BusAboardMap?stCode=00330593
- 明石台公園前: https://transfer.navitime.biz/miyagikotsu/pc/diagram/BusAboardMap?stCode=00332506
- 泉中央駅（東向陽台線・新富谷ガーデンシティ線の系統一覧）: https://transfer.navitime.biz/miyagikotsu/pc/diagram/BusCourseSearch?busstopId=00330344

確認日: 2026年11月23日。ダイヤ改正日は路線ごとに異なり、各路線データ内の `revisionDate` に記録しています。

## 既知の制約・今後確認すべき点

開発時の公式サイト調査で判明した制約です。実運用前に目を通してください。

1. **明石台七丁目は便数が非常に少なく、夜間の運行がありません。**
   平日でも泉中央駅発の最終は20:05、土日祝は18:45です。夜の飲み会帰りはほぼ必ず明石台公園前を使うことになります（このアプリの「帰り」検索はこれを前提に設計しています）。
2. **明石台七丁目方面への「到着時刻」は未確認です。**
   明石台七丁目は終点のため、公式サイトに同停留所の到着時刻表が存在しません。本アプリでは「泉中央駅発車時刻」のみを表示しています。
3. **明石台公園前の泉中央駅方面時刻表には「仙台駅前行き（泉警察署経由）」も掲載されていますが、実際に泉中央駅を経由するか未確認のため、本アプリの候補からは除外しています。**
4. **年末年始・お盆・祝日の特別ダイヤは未調査です。** `data/timetable.json` の `specialScheduleDates` で手動指定できますが、まずは公式サイトで確認してください。
5. リアルタイムの遅延・運休情報は取得していません。表示される「残り時間」はあくまで登録された時刻表に基づく参考値です。

## 技術仕様

- HTML / CSS / JavaScript のみ（外部ライブラリなし、ビルド不要）
- 時刻表データ: `data/timetable.json`（アプリ本体と分離）
- 祝日判定: 内蔵の計算ロジック（ハッピーマンデー・春分/秋分の近似式・振替休日・国民の休日に対応。外部API不要）
- オフライン対応: Service Worker によるキャッシュ（時刻表データはネットワーク優先、取得できない場合は最後にキャッシュした内容を使用）
- GitHub Pages で無料ホスティング可能
- 外部有料API・サーバー常時稼働は不要
- ログイン機能・ユーザー登録なし（個人利用専用）
